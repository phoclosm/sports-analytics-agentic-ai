# Sports Analytics with Agentic Two-Pass AI

## Overview
A multimodal sports analytics platform that combines Computer Vision, Agentic AI, and Machine Learning to analyze player performance across Basketball, Football, and Tennis.

## Key Features
- ResNet34 Sports Classification
- YOLOv8 Object Detection
- Agentic Two-Pass (Skim + Focus) Architecture
- Player Ranking and Clustering
- Performance Forecasting
- Interactive Analytics Dashboard

## Results
- 97% Sports Classification Accuracy
- 94.8% Overall System Accuracy
- ~65% Reduction in Token Consumption

## Tech Stack
Python, PyTorch, OpenCV, ResNet34, YOLOv8, Scikit-Learn, PCA, K-Means, Streamlit
